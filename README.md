# AI CV & Job Assistant 🚀

AI-powered platform that matches your CV with job postings and provides personalized improvement suggestions.

## 📋 Project Overview

This application helps job seekers:
- Upload their CV and job postings
- Get AI-powered matching analysis
- Receive improvement suggestions
- Generate tailored cover letters
- Identify missing competencies

## 🎯 Features

### MVP (Phase 1)
- ✅ CV upload (PDF support)
- ✅ Job posting input
- ✅ AI matching analysis
- ✅ Improvement suggestions
- ✅ Basic cover letter generation

### Future Features (Phase 2+)
- Interview question suggestions
- Salary negotiation tips
- LinkedIn optimization
- Application tracking
- Multiple language support

## 🛠️ Tech Stack

### Frontend
- **Framework:** React 18+
- **Forms:** React Hook Form
- **File Upload:** Dropzone
- **API Client:** Axios
- **Styling:** CSS Modules / Tailwind CSS

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB / PostgreSQL
- **AI Integration:** OpenAI API / Claude API
- **PDF Processing:** pdfkit / pdf-parse
- **Authentication:** JWT

## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/SanjaStosic/ai-cv-job-assistant.git
cd ai-cv-job-assistant
```

2. Setup Frontend
```bash
cd frontend
npm install
npm start
```

3. Setup Backend
```bash
cd backend
npm install
npm run dev
```
